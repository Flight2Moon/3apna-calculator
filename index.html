What this tool computes

3APNa is a gradient-boosted survival model (GradientBoostingSurvivalAnalysis, Cox partial-likelihood loss) fitted to five variables recorded before transarterial chemoembolisation: albumin, platelet count, alpha-fetoprotein, sodium and age.

Every boosting stage is a depth-1 stump, so the fitted ensemble is exactly additive. It collapses, with no loss of precision, into one step function per variable: 

F(x) = c + g_albumin(x) + g_platelet(x) + g_AFP(x) + g_sodium(x) + g_age(x)

S(t | x) = exp( -H0(t) · exp(F(x)) )
risk(t)  = 1 - S(t | x)

H0 is the Breslow baseline cumulative hazard estimated on the development cohort. Risk groups come from cut-offs fixed during model development: RO separates Low from Intermediate (a rule-out boundary, chosen for sensitivity) and RI separates Intermediate from High (a rule-in boundary, chosen for specificity).

Reproducibility

The browser implementation is checked against the original Python pipeline on every export: the collapsed step functions must reproduce pipeline.predict to within 1e-9, and tests/verify.js re-checks the JavaScript against Python reference scores. The agreement log is in the repository.

Limitations

  • Developed in patients treated with transarterial chemoembolisation. It does not apply to other treatments or to untreated disease.
  • Predictions are averages over patients with the same five values. They are not statements about an individual outcome.
  • Absolute probabilities depend on the baseline hazard of the development cohort. A population with different survival will need recalibration.
  • Youden-derived thresholds reported in the source analysis were computed on the test set; the risk-group boundaries above were fixed separately.
  • Values far outside the development range are extrapolation. The calculator flags them but still returns a number.
